# 📆 C++ Calendar Range Iteration Engine

A modular C++ console tool that systematically processes and displays sequential days across months, starting from the beginning of the year up to a specified calendar date.

## 🚀 Key Technical Highlights
- **Conditional Boundary Termination:** Dynamically breaks the inner day loop upon matching both target month and day conditions without hardcoding day limits.
- **Dynamic Leap Year Resolution:** Accurately factors century leap exceptions to calculate February's exact boundary ($28$ vs $29$ days).
- **Clean Modular Design:** Segregated functional architecture for user inputs, date validation, and display formatting.

## 🛠️ Tech Stack
- **Language:** C++
- **Paradigms:** Procedural Programming, Loop Control Flow, Date Arithmetic
